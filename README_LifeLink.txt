# LifeLink Web App

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run lifelink_app.py`

## Deploy online
1. Create a GitHub repository and upload `lifelink_app.py` and `requirements.txt`.
2. In Streamlit Community Cloud, create an app from that repository.
3. Set the main file path to `lifelink_app.py`.
4. Deploy and share the generated public URL.

The app loads illustrative demo records automatically. Use the Reset Demo Data button to restore the starting state. This is an educational DSA prototype, not a clinical blood-bank system. Blood compatibility, eligibility rules, and area distances are project demonstration logic only.
